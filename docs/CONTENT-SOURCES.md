# Content and assets

Content checked on 10 October 2026. This is an independent website concept for the general ILM Group of Colleges, Pakistan. Campus availability, fees and admission dates must be confirmed with the college. No admission-open announcement, ranking, statistics or testimonials have been invented.

- Programs and head-office phone, email, address and hours: [ILM official website](https://ilm.edu.pk/).
- Campus directory: [ILM campus network](https://ilm.edu.pk/ilm-network.php).
- Admissions overview: [ILM admissions information](https://ilm.edu.pk/adminssions.php). Applications are handled by the college; this site contains email/phone and official-site links rather than an application submission backend.
- Library image: [Unsplash image](https://images.unsplash.com/photo-1507842217343-583bb7270b66), used as an illustrative library photo, not an ILM campus photograph. [Unsplash license](https://unsplash.com/license).
- Local fonts: [Manrope](https://github.com/google/fonts/tree/main/ofl/manrope) and [DM Serif Display](https://github.com/google/fonts/tree/main/ofl/dmserifdisplay), under the SIL Open Font License. License copies are included in this directory.
- Text-based wordmark and favicon are custom design elements for this concept, not the college's original logo.

All browser assets are included in `site/assets/`; the page makes no external font, image or JavaScript requests.
